# CaMenu

A visually distinctive, responsive restaurant menu built with Next.js, TypeScript, and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Customizing menu content

Edit `src/data/menu.ts` to change categories, dishes, prices, descriptions, and image placeholders. The category images and dish images are intentionally represented by local placeholder paths under `public/images/` so you can add your own photography without changing components.
